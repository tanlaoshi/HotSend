- **产品名**：HotSend  
- **本仓路径**：`~/HotSend`（独立 Git 库，**不**在 Blocks 树内）  
- **文档**：[`Docs/`](Docs/)  
- **源码**：[`Code/`](Code/)（Protocol ✅；Cli/Gui 按 PR 推进）  
- **产物**：[`Build/`](Build/)（不入库二进制）  
- **协议对表**（姊妹仓 Blocks）：板端 `Kernel/HAL/Common/Ksend/`；现网对照 `Tools/ksend.py`（HotSend 绿之前保留）
