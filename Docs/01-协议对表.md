# 01 · 协议对表（HotSend ↔ 板端 Ksend）

权威实现对照：

- 板：`Kernel/HAL/Common/Ksend/`（`Serve.c` / `Receive.c` / `Private.h` …）  
- 现网主机：`Tools/ksend.py`（HotSend 未绿前保留；字节语义以板 + 本文为准）

HotSend **不另起 OTA**；只做同形主机端。

## 传输

| 路 | 主机 | 板 |
| --- | --- | --- |
| **主** | TCP connect → 板 `ip:port` | `ksend serve`（可选端口；默认 **26992**）；`INADDR_ANY` |
| **备** | 串口（如 `/dev/ttyUSB0`，115200） | 壳直接跑 ksend 协议（无 serve 时） |

有线 / Wi‑Fi 对 HotSend 无协议差；差在板主口与 RTT。地址以板壳 `ip`（`via wired` / `via wifi`）为准。

## 常量

| 名 | 值 | 说明 |
| --- | --- | --- |
| 块大小 | 4096 | 差量单位 |
| Magic | `0x4B53424B` | 小端块头 |
| Trailer index | `0xFFFFFFFF` | 收尾帧 |
| Abort index | `0xFFFFFFFE` | 主机中止 |
| ACK | `'A'` (0x41) | 块已接受（进批缓冲） |
| NAK | `'N'` (0x4E) | 重发本块 |
| 默认 TCP 口 | 26992 | 与板 `KSEND_TCP_PORT_DEFAULT` 一致 |
| 路径上限 | 95 可打印 ASCII + NUL 策略对齐板 `KSEND_PATH_BYTES`（96 含 0）；备份名 `.bak` 须塞进同一上限 |
| 文件上限 | 8 MiB | 与现网一致 |

CRC32：与 `ksend.py` / 板 `KsendCrc32*` **同一多项式与初值约定**（移植时对表 py `zlib.crc32` 与板实现，禁止「自造 CRC」）。

## 会话顺序

```
PC → 板   文本行：ksend\n
          或 ksend <目标路径> [--no-reboot] [--no-backup]\n
板 → PC   KSEND READY size=<旧> block=4096 n=<旧块数> [win=<1..16>] [via=wired|wifi|serial]\r\n
板 → PC   n × u32 旧块 CRC32（小端）+ 1 字节 '\n'
PC → 板   仅差量块：每块
            u32 magic | u32 index | u32 len | u32 crc32 | data[len]
板 → PC   'A' 或 'N'（每块一应答；`win>1` 时 PC 可流水后再收齐 ACK）
PC → 板   trailer：magic | 0xFFFFFFFF | 0 | 整文件 CRC32
板 → PC   KSEND OK crc=… written=… size=…
            prepare=… ready=… receive=… net=… flush=… finish=… verify=… install=… total=…
          或 KSEND FAIL …（及可能的 RESTORED）
```

- 默认路径不带参数时，可发裸 `ksend\n`（与旧 py 兼容）。  
- 换路径 / `--no-reboot` / `--no-backup` 时走带参文本行。  
- 板注：`'A'` = **该窗已落盘**（按 `win` 攒批一次 WriteAt 后再齐发）；整文件校验仍在 OK 前。  
- **`win=` / `via=`（nuc-1/2）**：有线 TCP `win=8 via=wired`；Wi‑Fi / 串口 `win=1` 且 `via=wifi|serial`。Wi‑Fi **不**报有线窗。`'N'` 后板丢弃其它 index 载荷，PC go-back-N。  
- **阶段墙钟（PR-KSEND-PHASE-FLUSH）**：`receive=net+flush`（`flush`=WriteAt 累计；`net`=其余收窗）；`finish≈verify+install`（`verify`=sync+盘回读；`install`=staging/.crc）。TCP 时 `ksend: phase …` 只上壳串口，HotSend 抄 **OK 行**字段。
## 差量

- 主机算本地每块 CRC，与板表比较；只发不同块。  
- 板上无文件 / 已 `rm` → 全量（`written` ≈ 总块数）。  
- 中止：发 abort 帧，板侧回滚策略对表现网。

## 超时（首期默认，可配置）

与现 `ksend.py` 同量级起步：READY 180 s；块 ACK 30 s（Gui/CLI 可加大）；表读取 / 校验可配置。  
**分路径（nuc-2）**：有线/串口默认不睡（仅显式 `--pace-ms > 0`）；`via=wifi`（或旧板 TCP+`win=1`）在 pace 未设时自动 500 ms/ACK（同 `--steady-throttle`）。每 16 块再 `max(N/1000,0.5)×4` 秒。
## 退出语义（CLI）

| 码 | 含义 |
| --- | --- |
| 0 | `KSEND OK` |
| 1 | `KSEND FAIL` |
| 2 | 传输/协议错误 |
| 3 | 本地参数/文件错误 |

Gui 用状态文案 + 日志，不依赖退出码给用户看。
