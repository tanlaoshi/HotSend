# 04 · Gui 草案（PR-3）

原则：一块屏一件事；无卡片堆砌；无仪表盘式首屏。

## 窗体一屏

| 区 | 控件 | 说明 |
| --- | --- | --- |
| 标题 | 「HotSend」 | 品牌级，不弱于正文标题 |
| 传输 | TCP / 串口 二选一 | 首期 TCP；串口 PR-4 再亮 |
| 目标 | Host 输入；端口（默认 26992） | 串口时改为设备路径 |
| 文件 | 本地路径 +「浏览」 | 默认可记上次；候选对齐常见 `Kernel/Build/.../Kernel.elf` |
| 板上路径 | 文本 + 预设下拉 | 例：`BLOCKS:Kernel.elf`、`D:Kernel.elf` |
| 选项 | 不重启；跳过备份；稳妥节流（默认关） | 文案短 |
| 动作 | 「开始」「中止」 | 传输中禁用开始；中止走 abort |
| 进度 | 一条进度条 + 一行状态 | `sent a/b (c%)` / `KSEND OK` |
| 日志 | 只读多行文本 | 板 note / 错误；等宽字体 |

## 线程

- 协议跑 **worker 线程**（或 `GTask`）；禁止在 GTK 主线程里堵 TCP。  
- 进度用 idle/marshal 回主线程更新条与日志。  
- 关窗：若在传，先 abort 再拆连接。

## 不做（Gui 首期）

- 多板会话标签页  
- 内嵌终端模拟板壳  
- 系统托盘常驻  
- 暗色特效 / 渐变堆砌（跟系统 GTK 主题走即可）

## 依赖

- GTK 4；Ubuntu 包 `libgtk-4-dev`。  
- Adwaita 可选（后排），不挡 MVP。
