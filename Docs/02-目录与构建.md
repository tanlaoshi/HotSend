# 02 · 目录与构建

## 树（目标形态）

```
HotSend/
  README.md
  .gitignore
  Docs/                 # 本文档集
  Code/
    Protocol/           # 纯 C 协议库（无 GTK）
    Cli/                # 可选命令行
    Gui/                # GTK4 窗体
    Meson.build         # 或顶层 meson.build
  Build/                # 产物目录（gitignore 二进制）
```

PR-1 起：`Code/Protocol/` + 顶层 `meson.build`。

## 构建系统

- **Meson + Ninja**（Ubuntu 原生友好）。  
- 配置示例：

```bash
cd ~/HotSend
meson setup Build/meson
meson compile -C Build/meson
# 产物：Build/meson/Code/libhotsend_protocol.a
#       Build/meson/Code/hotsend-smoke-tcp
```

- 依赖（APT）：`meson` `ninja-build` `zlib1g-dev` `build-essential`；Gui 另需 `libgtk-4-dev`。  
- **不**引入 Python 运行时；对照金样仍在 Blocks `Tools/ksend.py`。

## 默认配置与运行

仓库根 `hotsend.conf`（可改）。查找顺序：`$HOTSEND_CONFIG` → `./hotsend.conf` → `~/.config/hotsend/hotsend.conf` → `~/HotSend/hotsend.conf`。CLI 参数覆盖配置。

```bash
cd ~/HotSend && meson compile -C Build/meson
# 无参：用配置热传
Build/meson/Code/hotsend
# GUI
Build/meson/Code/hotsend-gui
```

## 图标与鼠标双击

```bash
cd ~/HotSend
chmod +x Tools/install-desktop.sh
./Tools/install-desktop.sh
```

会安装：

- 图标 → `~/.local/share/icons/hicolor/…/{hotsend,com.blocks.hotsend}.png`
- 应用菜单 → `~/.local/share/applications/com.blocks.hotsend.desktop`（文件名=应用 ID，**Dock 靠这个对齐**）
- 若有桌面目录（`xdg-user-dir DESKTOP`，中文环境多为 `~/桌面`）→ 同上 desktop（已 `chmod +x` / trusted）

之后可在应用菜单搜 **HotSend / 热传**，或桌面图标双击。  
**Dock 图标**：先完全退出 Gui，再从菜单/桌面启动（不要直接跑 `Build/.../hotsend-gui`）；若仍是齿轮，可把图标拖到 Dock 固定一次。首次若 GNOME 提示「取消/启动」，点启动或右键「允许启动」。

## 与 Blocks 仓关系

| 路径 | 关系 |
| --- | --- |
| `~/HotSend` | 本仓；主机工具；独立 remote |
| `~/Blocks`（或其它克隆） | 姊妹仓；联调时读其 ELF / 对表 py |
| `Blocks/.../Kernel/HAL/Common/Ksend/` | 板端；HotSend **不** `#include` 板树；协议靠文档 + 对表测试 |
| `Blocks/.../Tools/ksend.py` | 对照金样；HotSend 全绿并文档宣布退役前保留 |

## 编码约束（对齐 Blocks）

- 新写 `.c` / `.h`：**名字写全**；单文件 **≤300 行**；**文件名不**再加 `HotSend` 前缀（目录已分 `Protocol`/`Cli`/`Gui`）。  
- 公开 **符号** 前缀仍用：`HotSend…`（与产品名对齐，避免与系统符号撞）。  
- 注释写清与板注冲突时以 **板端现注 + 真机证据** 为准。
