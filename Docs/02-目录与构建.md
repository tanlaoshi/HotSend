# 02 · 目录与构建

## 树（目标形态）

```
HotSend/
  README.md
  .gitignore
  Docs/                 # 本文档集
  Code/
    Protocol/           # 纯 C 协议库（无 GTK）
    Cli/                # 可选命令行
    Gui/                # GTK4 窗体
    Meson.build         # 或顶层 meson.build
  Build/                # 产物目录（gitignore 二进制）
```

本刀（文档 + 占位）仅有 `Code/.gitkeep`；源码随 PR-1 起落入 `Code/`。

## 构建系统

- **Meson + Ninja**（Ubuntu 原生友好）。  
- 配置示例：

```bash
cd HotSend
meson setup Build/meson --prefix=/usr/local
meson compile -C Build/meson
# 产物：Build/meson/hotsend-cli 、Build/meson/hotsend-gui 、libhotsend_protocol.a
```

- 依赖（APT 名，实现 PR 再钉版本）：  
  - 协议库：仅 libc（TCP：BSD socket）；串口 PR 再定 `termios`。  
  - Gui：`libgtk-4-dev`（可选后期 `libadwaita-1-dev`）。  
- **不**引入 Python 运行时；**不**把 `Tools/ksend.py` 编进 HotSend。

## 与 Blocks 仓关系

| 路径 | 关系 |
| --- | --- |
| `~/HotSend` | 本仓；主机工具；独立 remote |
| `~/Blocks`（或其它克隆） | 姊妹仓；联调时读其 ELF / 对表 py |
| `Blocks/.../Kernel/HAL/Common/Ksend/` | 板端；HotSend **不** `#include` 板树；协议靠文档 + 对表测试 |
| `Blocks/.../Tools/ksend.py` | 对照金样；HotSend 全绿并文档宣布退役前保留 |

## 编码约束（对齐 Blocks）

- 新写 `.c` / `.h`：**名字写全**；单文件 **≤300 行**。  
- 公开 API 前缀：`HotSend…`。  
- 注释写清与板注冲突时以 **板端现注 + 真机证据** 为准。
