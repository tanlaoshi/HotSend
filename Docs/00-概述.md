# 00 · HotSend 概述

| 项 | 内容 |
| --- | --- |
| **产品名** | HotSend |
| **定位** | Ubuntu 桌面主机侧「热传」：差量写板端文件（内核 ELF 等） |
| **仓库** | 独立 Git：`~/HotSend`（与 Blocks 姊妹，不进 Blocks 树） |
| **替代目标** | 逐步替代日常对 Blocks 仓内 `Tools/ksend.py` 的依赖（协议兼容，非另起 OTA） |
| **非目标（首期）** | 板上 GUI；自动发现 / mDNS；替板执行 `ksend serve`；Windows/mac；ksend 板侧双缓冲提速 |

## 一句话

板上已 `ksend serve`（或串口壳在听）→ 主机 HotSend 选文件与目标路径 → TCP/串口按 **现网 ksend 帧** 差量写盘 → `KSEND OK`。

## 分层

```
┌─────────────────────────────┐
│  HotSend Gui（GTK4）         │  选文件 / Host / 进度 / 日志
├─────────────────────────────┤
│  HotSend Cli（可选薄封装）   │  脚本与 CI；参数对齐旧 ksend.py 习惯
├─────────────────────────────┤
│  HotSend Protocol（纯 C 库） │  协议 + TCP/串口传输；无 GUI 依赖
└─────────────────────────────┘
         │
         ▼
   板端 Ksend serve / 串口 ksend
```

- **协议库**与 GUI 解耦：库可单测、可先 CLI 对表 `ksend.py`，再挂窗。  
- **命名**：对外产品名 HotSend；库内公开符号用全称前缀（如 `HotSendTransferStart`），禁砍字缩写顶全称。  
- **单文件 ≤300 行**（Blocks 自有 C 铁律）；将满先拆。

## 真机判绿（库 / CLI 先行）

1. NUC：拔或插线 → 板 `ip` → `ksend serve` → HotSend TCP → `KSEND OK`（差量 + 一次 `rm` 后全量）。  
2. 同条件与 `Tools/ksend.py --host …` 对照：CRC / `written` 合理。  
3. Gui：同上路径可点选完成，不要求比 CLI 更多协议语义。
