# 03 · PR 拆分

原则：每个 PR **可单独合入、可单独验收**；先库后窗；先 TCP 后串口；不跟板侧 `net-ksend-1` / Pi header 绑死同一提交。

| PR | 名 | 内容 | 验收 | 依赖 |
| --- | --- | --- | --- | --- |
| **PR-0** | `hotsend-docs-0` | 本目录骨架：`HotSend/{Docs,Code,Build}`、概述/协议/构建/拆分/Gui 草案 | 文档自洽；无强制功能码 | — |
| **PR-1** | `hotsend-protocol-tcp-1` | `Code/Protocol/`：TCP 会话、READY/表/差量块/trailer/OK·FAIL；单元或主机侧自测钩子 | 对 NUC（或 virt）`ksend serve`：`KSEND OK`；与 `ksend.py` 对照差量/全量 | PR-0 |
| **PR-2** | `hotsend-cli-2` | `Code/Cli/`：参数近似 py（`--host`/`--file`/`--path`/`--no-reboot`…） | CLI 全量/差量绿；退出码表对齐 [01](01-协议对表.md) | PR-1 |
| **PR-3** | `hotsend-gui-3` | `Code/Gui/`：GTK4 最小窗（见 [04](04-Gui草案.md)）；后台线程跑协议，UI 只收进度 | 点选灌 NUC 有线 → OK；卡 UI 禁止 | PR-1（Cli 可选） |
| **PR-4** | `hotsend-serial-4` | 协议库串口传输 + Cli/Gui 入口 | Duo/Pi/NUC 串口备份路径绿 | PR-1 |
| **PR-5** | `hotsend-extras-5` | `--info` / `--dry-run` / 可选稳妥节流；文档写清与 py 退役条件 | 信息查询与干跑可用 | PR-2 |

## 明确不进上述 PR

- 板侧有线批写 / 滑窗 / 吞吐（**1108 核传柱**，见 Blocks `路线图1108.md` + 本仓 [05](05-当前星.md)）。  
- 板侧 `BatchFlush` 双缓冲 / 删 ACK 挡盘（并入「核传-有线批写」）。  
- `ksend-freeze-ui`（板桌面冻结窗）。  
- Pi TCP `reason=header` 修复（活 ★ `net-ksend-1`）。  
- 自动扫网发现板 IP。

## 建议合入顺序

```
PR-0 文档骨架
  → PR-1 Protocol TCP
      → PR-2 Cli ──→ PR-5 extras
      → PR-3 Gui
      → PR-4 Serial（可与 Gui 并行，合入前 rebase）
```

```

```

不把无关 Kernel 改动塞进 HotSend PR。
